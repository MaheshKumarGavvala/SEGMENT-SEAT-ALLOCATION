SMART SEGMENT — PASSENGER DASHBOARD

This dashboard is an original product UI direction. The supplied dashboard was used only as a general UX reference; no sidebar was carried over.

Files:
- index.html
- style.css
- app.js

Highlights:
- Header-only navigation
- Premium light/dark theme control
- Fast theme transition
- Functional route autocomplete and validation
- Swap locations control
- Date selection
- Search flow opens the existing bus-search page when used inside the larger project
- Bookings actions open the existing booking-confirmation page
- Original Smart Segment explanation centered on one passenger and complete journey coverage
- Responsive desktop/tablet/mobile layout

Open dashboard/index.html in the context of the full project so relative booking/search paths resolve correctly.
