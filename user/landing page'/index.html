01 / THE IDEA

One passenger.
One complete journey.
Multiple seat segments.

Smart Segment is designed for the situation where a passenger needs to travel the entire route, but one physical seat is not available for every part of that journey.

Instead of stopping at “no single seat available”, the system can split the journey into consecutive segments and find available seats that together cover the complete trip.

07 / FAQ

Questions, answered
clearly.

A concise explanation of the Smart Segment experience.

Smart Segment is a journey-aware seat allocation concept that can divide one passenger’s complete journey into consecutive segments and combine available seats to cover the entire trip when one seat is not available throughout.
Normal seat selection generally looks for one seat covering the requested trip. Smart Segment can instead evaluate consecutive seat segments and build a complete allocation when a single seat cannot cover the journey.
No. It fits into the existing journey: search, choose a bus, apply smart allocation, enter passenger details, pay and receive the ticket.
Yes. The passenger can be shown the allocation clearly and can still use the seat map according to the booking rules. The important difference is that each allocated seat is tied to a specific journey segment.
The interface should clearly show the exact segment covered by each seat and the point where the passenger changes seats. A valid Smart Segment allocation must cover the journey continuously from boarding to destination.
