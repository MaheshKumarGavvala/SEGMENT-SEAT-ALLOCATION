SMART SEGMENT — PREMIUM MULTI-SEGMENT SEAT ALLOCATION HOMEPAGE

CORE PRODUCT CONCEPT
Smart Segment is NOT primarily about assigning different passengers to different route segments.

The central concept is:
A single passenger wants to complete one journey from Boarding Stop to Destination. If no single physical seat is available for the entire journey, Smart Segment can split the journey into consecutive segments and allocate available seats across those segments.

Example:
Boarding Stop → Stop 1 → Stop 2 → Stop 3 → Destination

Seat 12A:
Boarding Stop → Stop 2

Seat 18B:
Stop 2 → Destination

Complete passenger allocation:
12A → 18B

A valid allocation must cover every part of the journey without a gap.
